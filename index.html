03推送配置说明

本目录自带一个本地推送脚本 push-day.ps1（由 Windows 计划任务 DailyHandbookPush 在 09:00 / 12:30 / 登录时触发）。它做三件事：
① 按 plan.json 的日程算出今天该看第几天；② 把当天的「今日速览」作为飞书卡片推给你，卡片底部附本站页面链接；③ 写日志。

电脑弹窗已关闭：plan.json 里 "openInBrowser" 和 "notify" 都是 false，不再自动开浏览器、不再弹系统通知；想恢复就改成 true。
飞书已开通：Webhook 已写入 plan.json；想换群就换成新机器人的地址即可，保存后下一次触发生效。
手机看图文：页面发布在 GitHub Pages 上，地址写在 plan.json 的 "pageUrlBase"；卡片会自动拼上当天文件名。
改时间：改 plan.json 的 "time" / "catchUpTime"，然后重新运行 install-task.ps1。
查记录：每次运行都写进 push-log.txt；.last-push 记录最后推送日期，保证一天只推一次。
换周期：plan.json 的 "strideDays" 改成 2，就变成两天一章。
