# AI Agent HandBook · 每日一章（中文图解版）

把阿里云开源白皮书 [《AI Agent HandBook》](https://github.com/aliyun/ai-agent-handbook) 拆成 34 天的阅读计划：每天一页，两幅自绘 SVG 图，术语翻成人话，外加一节「跟我工作有什么关系」和 3 个自检问题。

- 入口：[index.html](index.html)（目录与进度）
- 每日页面：`day01.html` … `day34.html`
- 长章节（第 2、3、30 章）拆成上下两天
